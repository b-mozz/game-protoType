# PASS IF YOU CAN

A rhythm game about surviving a semester. Blocks of coursework spawn as
segments on a ring and shrink as they age — catch one with the sweeping bar
before it vanishes, or lose the credit. What you catch becomes your report
card.

## Dependencies

| | |
|---|---|
| [pygame-ce](https://pyga.me/) | 2.5.8 |
| Python | 3.13 |

```sh
pip install -r requirements.txt
python main.py
```
